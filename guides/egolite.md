# ego lite — Claude Code에게 브라우저 업무 맡기기

> 메일 확인, 자료 검색, 노션이나 구글 문서 같은 업무 툴까지 — 하루 업무 시간의 절반 이상을 브라우저 안에서 보내고 있다면, 그중 매번 똑같이 반복되는 일을 AI에게 맡겨 보면 어떨까요? **ego lite**는 Claude Code 같은 AI 에이전트가 **직접 열고, 클릭하고, 입력하면서** 브라우저 작업을 대신 처리할 수 있도록 만든 브라우저입니다. 설치부터 쇼핑몰 가격 비교, 해커뉴스 번역·요약, **로그인된 Gmail에서 영수증 정리**까지 — 그리고 내 계정을 맡기는 만큼 꼭 알아야 할 **안전하게 쓰는 방법**을 정리한 가이드입니다. 영상에서 사용한 프롬프트를 전부 담았습니다.
>
> 📺 영상 채널: **Aiden의 친절한 AI (https://www.youtube.com/@Aiden_channel)**

---

## 이 가이드로 하는 것

1. ego lite가 **"AI가 들어 있는 브라우저"가 아니라 "AI가 조작하는 브라우저"** 라는 걸 이해한다
2. ego lite를 설치하고 **기존 브라우저의 로그인 상태**를 가져온다
3. Claude Code에서 **`/ego-browser` 스킬**을 확인한다
4. 쇼핑몰 세 곳의 가격을 **여러 Space에서 동시에** 비교한다
5. 해커뉴스 상위 10개 글을 **번역·요약**해 표로 받는다
6. **로그인된 Gmail**에서 영수증 메일을 정리하고 라벨까지 단다
7. 내 계정으로 움직이는 AI를 **안전하게 쓰는 방법**을 익힌다

## 준비물

- **macOS 또는 Windows** — 원래 맥 전용이었고, 최근 **윈도우 베타 버전**이 나와 윈도우에서도 사용 가능
- **AI 에이전트** — 영상에서는 **Claude Code** 사용 (Codex, Cursor 같은 다른 에이전트에서도 사용 가능)
- (선택) **크롬 등 기존 브라우저** — 로그인 상태를 가져올 브라우저
- (선택) **테스트용 구글 계정** — 영상의 Gmail 시연은 샘플 메일을 넣어 둔 테스트 계정으로 진행

## 시작 전에 — ego lite는 무엇이고, 무엇이 다른가

> ⭐ **할 일만 말하면, AI가 ego lite를 열고 클릭하고 입력하면서 브라우저 작업을 대신 해 줍니다.** 우리가 평소에 쓰는 AI 에이전트에서 `/ego-browser` 스킬을 실행하면, AI가 ego lite 브라우저를 직접 조작하며 작업을 처리하는 방식입니다.

### 특징 ① AI가 들어 있는 브라우저가 아니라, AI가 조작하는 브라우저

|  | 어사이드 브라우저 (지난 영상) | ego lite |
| --- | --- | --- |
| **기본 방식** | 브라우저 안에 **내장된 AI**에게 일을 시킴 (CLI 연결도 가능) | Claude Code 같은 **AI 에이전트가 브라우저를 직접 운전** |
| **역할 분담** | 브라우저가 AI까지 포함 | 생각하고 판단하는 건 **Claude Code**, ego lite는 **AI가 몰기 좋게 만든 자동차** |

### 특징 ② Space — AI만의 작업 공간

AI는 내가 쓰는 탭이 아니라 **Space**라는 자기만의 공간에서 따로 작업합니다.

- 작업하는 동안에도 나는 **브라우저를 평소처럼 계속** 쓸 수 있음
- Space를 **여러 개 동시에** 띄울 수 있어, 쇼핑몰 세 곳을 한꺼번에 비교하는 작업도 가능
- ego lite **오른쪽 위 숫자**가 지금 돌아가는 Space 개수 — 눌러서 각 Space의 진행 상황을 볼 수 있고, 숫자가 사라지면 작업 완료

### 특징 ③ 로그인 상태를 그대로 이어받는다

설치할 때 기존 브라우저 데이터를 가져오면, **평소에 로그인해 둔 사이트를 AI도 로그인된 상태 그대로** 사용합니다. 기존 브라우저 자동화 도구들이 로그인 화면에서 자주 막혔던 문제를 해결한 부분이죠.

> 💡 **"내 계정을 AI한테 맡겨도 괜찮을까?"** — ego lite 측 설명에 따르면, 가져온 브라우저 데이터는 외부 서버가 아니라 **내 컴퓨터에만 저장**됩니다. 또 AI는 자기 Space에서 따로 작업하기 때문에 내가 열어 둔 화면을 함부로 건드리지 않습니다. 다만 AI가 내 계정으로 움직이는 만큼, 뒤에 정리한 **안전하게 쓰는 방법**은 꼭 확인하세요.

### 그 밖에

- 지도나 예약창처럼 **페이지 안에 따로 들어가 있는 영역**까지 읽을 수 있음
- **ego lite 자체는 무료**

> ⚠️ Claude Code 같은 AI 에이전트 사용 비용은 별도입니다. 브라우저 작업은 AI가 페이지를 여러 번 읽어 가며 진행하기 때문에, **일반적인 대화보다 사용량이 더 들 수 있습니다.**

## STEP 1. 설치와 기본 설정

1. ego lite 홈페이지 접속 → 화면 중앙 **다운로드** 버튼 → 다운로드 페이지로 이동
2. 설치 파일 저장 창이 뜨면 위치를 지정하고 **저장**
3. 받은 파일을 열어 설치 진행 → **시작하기** → **다음**
4. **기존 브라우저 데이터 가져오기** — 가져올 브라우저와 프로필을 선택하고 **데이터 가져오기** (지금 건너뛰고 나중에 설정해도 됨)
5. 이후 항목은 건너뛰고, **탭 스타일** 선택 (영상에서는 가로) → 기본 설정 완료

> ⭐ **데이터 가져오기가 핵심입니다.** 여기서 데이터를 가져오면 평소에 로그인해 둔 사이트들을 AI도 로그인된 상태 그대로 쓸 수 있습니다. 영상에서는 크롬에서 프로필 하나의 데이터만 가져왔습니다.

설정을 마치고 실행하면 **"환영합니다"** 문구와 함께 안내 페이지가 뜹니다. 새 탭을 열어 보면 겉모습은 평소 쓰던 크롬과 거의 똑같고, 안내 페이지에서 ego lite의 동작 방식을 확인할 수 있습니다.

---

## STEP 2. Claude Code에서 스킬 확인

ego lite를 설치하면서 **ego-browser 스킬도 함께 설치**되기 때문에 추가 설정은 필요 없습니다.

1. Claude Code 실행
2. 입력창에 `/ego`까지만 입력 → **ego-browser**가 뜨는지 확인

> 💡 ego-browser 스킬이 보이지 않는다면 **Claude Code를 한 번 껐다가 다시 실행**해 보세요.

이후 시연은 모두 **`/ego-browser` 스킬을 선택한 상태로** 요청합니다.

---

## STEP 3. 쇼핑몰 세 곳 가격 동시 비교 — 여러 Space ⭐

영상 오프닝 시연입니다. 무선 마우스 하나를 사려고 쇼핑몰 몇 곳을 하나씩 들어가 비교하던 일을 AI에게 맡깁니다.

```text
/ego-browser 쿠팡, 11번가, G마켓에서 '로지텍 MX Master 4 그래파이트' 가격을 각각 별도의 Space에서 동시에 확인해 줘. 쇼핑몰마다 가장 저렴한 새 상품 기준으로 판매처, 판매가, 배송비, 링크를 찾아서 마지막에 하나의 비교표로 정리해 줘. 장바구니 담기나 구매는 하지 마.
```

> ⭐ **이 프롬프트의 포인트**
>
> - **"각각 별도의 Space에서 동시에"** — 세 곳을 순서대로가 아니라 한꺼번에 확인
> - **비교 기준 명시** — 가장 저렴한 새 상품 기준, 판매처·판매가·배송비·링크
> - **"장바구니 담기나 구매는 하지 마"** — 해서는 안 되는 일을 분명하게

### 진행과 결과

- ego lite 오른쪽 위에 **숫자 3** — 세 개의 Space에서 각각 쿠팡, 11번가, G마켓에 접속해 작업 중
- 작업은 **백그라운드**에서 실행되어, 그동안 다른 일을 그대로 할 수 있음
- 숫자 3이 사라지면 완료 → Claude Code에서 **비교표와 참고할 사항**까지 정리된 결과 확인

---

## STEP 4. 해커뉴스 상위 10개 글 번역·요약

해커뉴스는 전 세계 개발자들이 IT 소식을 공유하는 커뮤니티입니다. 상위 10개 글을 찾아 핵심 내용을 정리하게 합니다.

```text
/ego-browser 해커뉴스(news.ycombinator.com) 메인 페이지에서 상위 10개 글을 찾아서 제목을 한국어로 번역하고, 각 글이 어떤 내용인지 한 줄로 요약해서 표로 정리해 줘. 원문 링크도 같이 넣어 줘.
```

### 진행과 결과

- 이번에는 작업이 하나라 오른쪽 위 숫자가 **1**, Space도 하나만 생성
- Space를 열어 보면 **테두리에 파란 빛**이 돌면서 작업 수행 중
- 작업이 끝나면 Space가 닫히고, Claude Code에 **번역된 제목·한 줄 요약·원문 링크** 표가 정리됨

---

## STEP 5. 로그인된 Gmail에서 영수증 정리 + 라벨 ⭐

로그인 상태를 활용하는 예제입니다. 영상에서는 **테스트용 구글 계정**에 샘플 메일을 넣어 두고 진행했습니다.

```text
/ego-browser 내 Gmail에서 이번 달에 받은 결제 영수증 메일을 찾아서 날짜, 업체명, 금액을 표로 정리하고 마지막에 합계도 계산해 줘. 날짜는 메일 본문에 적힌 결제일 기준으로 정리해 줘.

그리고 찾은 영수증 메일에 '영수증' 라벨을 달아 줘. 라벨이 없으면 새로 만들어도 돼.
라벨을 다는 것 말고는 답장, 삭제, 이동 등 메일에 아무것도 하지 마.
```

> ⭐ **이 프롬프트의 포인트**
>
> - **기준 명시** — 날짜는 메일 수신일이 아니라 **본문에 적힌 결제일** 기준
> - **허용 범위** — 라벨이 없으면 새로 만들어도 된다고 미리 허용
> - **금지 범위** — 라벨 달기 외에 답장·삭제·이동 등은 하지 않도록

### 진행과 결과

- 따로 로그인하지 않았는데도 **로그인된 상태 그대로** 메일함에 들어가 영수증 메일 검색
- '영수증' 라벨을 **새로 만들어** 메일에 하나씩 적용
- Claude Code에 **결제일·업체명·금액 표와 합계** 정리 — 같은 업체에서 온 광고·안내 메일은 빼고 **실제 결제 영수증만** 골라냄
- 메일함 왼쪽에 '영수증' 라벨이 생기고, 영수증 메일에만 라벨이 붙은 것 확인

## 안전하게 쓰는 방법 ⭐

로그인된 상태를 활용하면 정말 편하게 일을 맡길 수 있지만, 그만큼 **AI가 내 계정으로 직접 움직이는 것**입니다. 이 세 가지는 꼭 기억하세요.

| 원칙 | 방법 | 영상 예시 |
| --- | --- | --- |
| **① 범위를 분명하게** | 프롬프트에 해도 되는 일과 하면 안 되는 일을 적는다 | "라벨을 다는 것 말고는 답장, 삭제, 이동 등 메일에 아무것도 하지 마" |
| **② '권한 무시' 모드 쓰지 않기** | Claude Code 모드 메뉴의 '권한 무시'는 확인 없이 모든 작업을 허용 → 로그인된 브라우저를 다룰 때는 피하고, **기본값 '자동' 모드** 사용 | '자동' 모드에서는 Claude가 권한 결정을 처리하면서 위험한 동작을 한 번 더 걸러 줌 |
| **③ 마지막 버튼은 직접** | 결제·송금·메일 발송처럼 되돌리기 어려운 일은 AI에게 준비까지만 맡긴다 | "장바구니 담기나 구매는 하지 마" |

## 반복 작업이라면 — 한 단계 더

매번 반복하는 브라우저 작업이라면 한 번씩 시키는 데서 끝내지 말고,

- **스킬로 만들어 두거나**
- **예약 작업으로 걸어 두면**

정해진 시간마다 알아서 돌아가게 만들 수도 있습니다.
